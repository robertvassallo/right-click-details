================================================================
 RIGHT CLICK DETAILS - CHANGELOG
================================================================


================================================================
 v1.8
================================================================

FIXED

* Freight rows could name the wrong line, or no line at all, on
  anything larger than a starter network. Three separate faults sat
  on top of each other, and each one hid the next.

  Which lines carry a commodity was worked out from what each line
  had ABOARD at that moment. Empty is the normal state for a line -
  six of eight on a test save were carrying nothing - so carriers
  appeared and vanished between clicks, and goods nobody happened to
  be hauling showed no line at all. It now reads what each line's
  vehicles are CONFIGURED to carry, which does not change when a
  train runs empty.

  A station serving more than ten lines had the extras discarded
  BEFORE the lookup ran, not just before the list was drawn. A ten-
  line display limit was deciding what data existed: a station with
  twelve lines reported "--" for two commodities whose only carrier
  happened to sort eleventh, while the game's own window listed it
  the whole time. Every line is now read; only the ROWS are capped,
  and the busiest are kept.

  Finally the vehicle check itself sampled only the first few trains
  on a line. A line's fifth train can be set up differently from its
  first, so a commodity's only carrier was dropped at random - a row
  naming its line correctly one minute and showing "--" the next.
  Every train is read now.

* The panel no longer runs off the edge of the screen. It was always
  placed below and right of the cursor with no bounds check, so a
  click low on the screen cut the panel off - at any size, not only
  tall ones. It now flips above or left of the cursor when it would
  overflow.

  It flips rather than slides: sliding it up until it fits buries
  the cursor inside the panel, which triggers the "closes when the
  mouse moves" setting and hides what you just opened.

* Settings are saved again. The mod runs in more than one script
  context, and the message telling the one that writes the save
  about a changed setting used a call that context cannot make. It
  failed silently on every change, so every choice was lost on
  reload. This had been broken since it was written; the v1.5 note
  claiming it was fixed described code that never ran.


CHANGED

* A line with no colour set now shows a hollow ring instead of a
  grey disc, so it cannot be confused with the grey ring meaning
  "we cannot tell which line". They were previously the same colour
  and meant different things.

* Station throughput reads Outbound and Inbound rather than
  Outbound/yr and Inbound/yr. The figures are lifetime totals since
  the station was built and never were per-year.

* The town name shows in the panel heading by default.


================================================================
 v1.7
================================================================

FIXED

* Freight rows named the wrong line. At any station where two lines
  carry the same commodity, both collapsed into a single row
  labelled with whichever line happened to be found first - so a
  stop served by two liquid lines showed one and hid the other.

  The mod paired a commodity with a line by asking each line what it
  carries and taking the first match. That is only correct where one
  line serves a commodity, which is not true at an interchange.

  A line is now named only where it is the only one SEEN carrying
  that commodity. Where two or more are seen, the row reads "2
  lines" and shows no colour - the game does not record which line a
  waiting item is queued for - and each of those lines is listed
  beneath it with its own colour, so you still see who runs what.
  The amounts were always exact and are unchanged.

  Read a named line as "the only one we could see", not as proof.
  The check looks at what each line has ABOARD at that moment, and
  most lines are empty most of the time - on the save this was
  tested against, six of eight lines reported nothing in transit. A
  line that serves the stop but happens to be running empty is
  invisible to the check, so the same station can read "2 lines" one
  minute and a single name the next.

  That is still a long way better than what it replaces, which named
  whichever line was found first and hid the rest. But it is not the
  certainty a single name suggests, and saying so is cheaper than
  having you find out. A stable answer means asking each line what
  its vehicles are CONFIGURED to carry rather than what they happen
  to be holding, and that is planned rather than done.

* The per-line freight breakdown added in v1.6 never actually ran.
  It filtered on a field holding where cargo came FROM rather than
  where it waits, so it matched nothing and silently produced no
  rows - every station fell through to the per-commodity list. That
  code is removed rather than repaired: the call it relied on
  returns only cargo already loaded onto vehicles, so it could never
  have answered what is waiting at a stop.

  The v1.6 notes below say those counts "ARE for this stop
  specifically". They never were. That line is left standing as it
  shipped rather than quietly rewritten, and this entry corrects it.

* Station throughput was labelled per-year and never was. Outbound
  and Inbound now read as what they are - lifetime totals since the
  station was built.

  The numbers were always right; only the "/yr" on the label was
  wrong. The game keeps per-month and per-year counters but never
  fills them in, so the reading falls back to the running total. The
  industry panel had the identical fault and was corrected several
  releases ago - the station labels were missed in that sweep. A
  branch station reading "Outbound/yr 378.5K" with a single item
  waiting is what gave it away.

  A real per-year figure cannot be got by dividing what is there:
  the divisor would have to be the station's age, and nothing
  exposes a build date. Total game time is not a substitute - a
  station built late in a long game would read an order of magnitude
  low, and by a different factor at every station. Getting it right
  means sampling the total twice and differencing, which is planned.


CHANGED

* Town panels now match the station panels. Commodity figures line
  up in a column with their percentages recessive behind them, and a
  rule separates the population line from the list - the same
  treatment the station panels got in v1.6.

* A station lists at most ten lines, and says so in the log when it
  trims.

* The town name now shows in the panel heading by default. It used
  to appear only when the map label was hidden, which is seldom -
  so the one line telling you WHICH town you had hit was usually
  the line that was missing. If you have already chosen a setting
  it is kept; this only changes new games.


================================================================
 v1.6
================================================================

NEW

* Station readouts are now broken down BY LINE, with each line's
  own colour as a leading dot.

  Passengers show the exact number waiting at the stop, then each
  line serving it with the people travelling on that line. The two
  answer different questions: whether this stop is backing up, and
  which of its lines needs more capacity.

  Freight shows the total waiting here over the station's capacity,
  then one row per line and commodity - and those counts ARE for
  this stop specifically.

* Large figures are abbreviated, so 62500 reads as 62.5K instead of
  stretching the panel.

* Freight stations no longer list passenger lines with a zero
  beside them, which made a cargo yard look like a passenger
  interchange.


FIXED

* A line could show its colour at one station and a plain grey dot
  at another, and occasionally a line was missed from a station's
  list entirely.

  The mod works out which lines serve a station from the game's
  line-stop data, and what comes back is not always the line itself.
  Where it was something else, the colour lookup found nothing and
  the name could be wrong. Entries are now checked before use.


CHANGED

* Waiting totals are highlighted and carry their commodity icon, so
  the exact station figure stands apart from the per-line numbers
  below it. The highlight adapts to the panel theme - it was
  unreadable on the light theme.

* Throughput figures (Outbound/Inbound) are greyed, so they sit
  behind the line detail rather than competing with it.

* Cargo rows show the line's colour disc instead of an arrow,
  matching the passenger rows.


================================================================
 v1.5
================================================================

FIXED

* Settings did not survive a reload. Changing an option or toggling
  debug logging worked for the rest of the session, but the choice
  was gone next time the save was loaded.

  The mod runs in more than one script context, each holding its own
  copy of the settings. The settings panel writes to one of them; the
  code that stores settings in the savegame reads another. Choices
  were being made in a copy nobody ever saved, so nothing reached the
  save at all - the earlier attempts at this were all fixing the wrong
  end. Changes are now sent between contexts as they happen.


================================================================
 v1.4
================================================================

NEW

* Toolbar button restyled to match the game's own bar buttons -
  same disc, same size, same hover and pressed states.

* Debug logging is back in the settings panel, as a ladybug in the
  bottom corner. Dim when off, red when on. It was moved out to the
  main-menu mod options in v1.3, which turned out to be unreachable
  for a save already in progress.

* Large figures are abbreviated. A commodity sitting on 62500 units
  reads as 62.5K instead of stretching the panel.


FIXED

* Produced, Shipped and Used all read 0 on every industry. The game
  keeps per-month and per-year counters but never fills them in, so
  the mod was faithfully reporting an empty total.

* Right-clicking the same spot again never cycled to the next thing
  nearby. Opening a panel discarded the cycle it had just built, so
  every right-click started over from the top. This had never worked
  for any object type.

* Stations and stops inside a town were unreachable - the town won
  the first click, and cycling past it was the thing that did not
  work.

* Settings saved with your game were overwritten on load. The mod
  applied the savegame first, then wrote the menu defaults back over
  it, so a choice made in the panel survived only until the next
  load.

* Changing a setting in the main-menu mod options did nothing at all
  on a save that had already been played. Mod options and in-game
  choices are now told apart, so the one you changed is the one that
  wins.


CHANGED

* Produced, Shipped and Used are lifetime totals since the industry
  was built, and are labelled without "/yr". They were previously
  described as trailing twelve-month figures, which the game's
  counters do not actually provide.

* The low-stock highlight is temporarily switched off. It compared
  stock against a per-year consumption rate; with only lifetime
  totals available that comparison would flag every row. It returns
  when the mod can measure a real rate.


================================================================
 v1.3
================================================================

NEW

* Settings now stick. Changing an option and reopening the panel
  kept showing the old value - the mod was restoring saved data
  over your choices while you played.

* Town name setting: show it always, only when town labels are
  hidden by the HUD filter, or never.

* Escape closes the detail panel or the settings window. It only
  does so while one is open, so Escape still opens the game menu
  the rest of the time.

* "Closes on: Mouse moves" works. It never fired before because
  mouse listeners only receive button events, not movement.


FIXED

* Passengers on train and tram stations showed "--" instead of the
  line they are waiting for. People are not cargo and needed a
  different lookup.

* Stored amounts on industries. Single-input industries such as
  quarries and brick works now show their exact stock. Industries
  with several inputs show a combined "Stored total" instead - the
  game does not expose which stock slot holds which commodity, and
  a combined figure is better than a confidently mislabelled one.

* Right-clicking near an industry rather than on it picked the
  wrong object, and the same industry could report different
  numbers depending on where you clicked.

* Bus stops, tram stops and depots were sometimes skipped in favour
  of whatever was nearby.

* Settings controls are buttons that cycle through their options.
  Dropdowns were tried but did not reliably report changes.


CHANGED

* Debug logging moved out of the in-game panel. It is a support
  switch rather than a preference, and still available in the mod
  options from the main menu.

* The mod no longer writes diagnostics to the game log unless debug
  logging is switched on.


================================================================
 v1.2
================================================================

NEW

* In-game settings panel. Open it with the mouse button on the right
  of the HUD bar. Turn the panel on or off, choose how it closes,
  pick a theme, and toggle debug logging. Settings are saved with
  your game.

* Three ways for the panel to close - click off, on mouse move, or
  sticky (stays until you right-click it again).

* Panel themes: Dark, Darker and Light.

* Bus stops, tram stops and depots now have their own readouts.

* Industry names are led by the commodity they produce, so quarries,
  farms and oil wells say what they are at a glance.

* Names are shown as titles. A town's name appears only when town
  labels are switched off in the HUD filter, so it is never a
  duplicate of the label right above it.

* Bevelled panel corners.


FIXED

* The panel no longer disappears when you move the mouse.

* Modded commodities now show up. Cargo types are read from the live
  registry instead of a fixed list, so cargo-adding mods work.
  Tested alongside Freestyle Industries.

* Stored amounts named the wrong commodity - every stored row was
  showing the next commodity along.

* Industry readouts changed depending on exactly where you clicked.
  An industry exists as two linked objects and only one carried the
  production data; both now resolve to the same one.

* You had to click near an industry rather than on it. The search
  area was far too generous.

* Industry stocks listed outputs alongside inputs, leaving half-empty
  rows. Inputs only now, matching the game's own Stocks table.

* Commodity icons stretched and squashed.

* Middle-click no longer closes the panel, since it pans the camera.


CHANGED

* Rate figures now say what period they cover - Produced/yr,
  Shipped/yr, Used/yr, Outbound/yr, Inbound/yr. These are trailing
  twelve-month totals from the game's own counters. The industry
  window shows a live rate over capacity, which is calculated
  internally and is not available to mods, so the two will not match.
  Stored is a live figure and does match.

* Station throughput reads Outbound and Inbound rather than Loaded
  and Unloaded, which was ambiguous in a small panel.

* City labels are left at their default size. Earlier versions made
  the commodity icons on them larger; that is now opt-in.

* Diagnostics are off by default. Turn on Debug logging in the
  settings if you are reporting a problem.
